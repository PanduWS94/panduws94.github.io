Proyek Web UI Testing

Saya memiliki beberapa proyek untuk Web UI Testing menggunakan berbagai tools dan framework modern. Setiap proyek dirancang untuk menunjukkan kemampuan dalam automation testing, component testing, dan end-to-end testing dengan best practices.

1. Playwright Web UI Automation

📌 Overview

Automation testing menggunakan Playwright, sebuah browser automation library yang modern dan powerful untuk testing web applications.

  • Framework: Playwright, Node.js
  • Test Type: Component Testing, Regression Suite
  • Reporting: HTML Report, Screenshots on failure
  • Repository: GitHub

2. Cypress E2E Automation with BDD

📌 Overview

End-to-end testing menggunakan Cypress dengan Behavior-Driven Development (BDD) approach. Menggunakan Gherkin syntax untuk mendefinisikan test scenario yang lebih readable.

  • Framework: Cypress, Cucumber
  • Approach: BDD (Behavior-Driven Development)
  • Test Type: Component Testing, Regression Suite, E2E
  • Reporting: Mochawesome, Video Recording
  • Repository: GitHub

3. WebDriverIO Web UI Automation

📌 Overview

Automation testing menggunakan WebDriverIO dengan WebDriver protocol. Fleksibel dan dapat digunakan untuk web dan mobile automation.

  • Framework: WebDriverIO, JavaScript
  • Test Type: Component Testing, Regression Suite
  • Reporting: HTML Report
  • Repository: GitHub

4. Katalon UI Automation

📌 Overview

Automation testing menggunakan Katalon Studio, sebuah all-in-one automation testing platform. User-friendly dengan built-in features untuk test management dan reporting.

  • Tool: Katalon Studio
  • Test Type: Component Testing, Regression Suite
  • Reporting: Built-in HTML Report
  • Repository: GitHub

Contoh Playwright Test Case

import { test, expect } from '@playwright/test';

test.describe('Login Functionality', () => {
  test('should login successfully with valid credentials', async ({ page }) => {
    await page.goto('https://example.com/login');
    
    // Fill login form
    await page.fill('[name="email"]', 'test@example.com');
    await page.fill('[name="password"]', 'password123');
    
    // Click login button
    await page.click('button[type="submit"]');
    
    // Verify successful login
    await expect(page).toHaveURL('https://example.com/dashboard');
    await expect(page.locator('text=Welcome')).toBeVisible();
  });

  test('should show error with invalid password', async ({ page }) => {
    await page.goto('https://example.com/login');
    
    await page.fill('[name="email"]', 'test@example.com');
    await page.fill('[name="password"]', 'wrongpassword');
    await page.click('button[type="submit"]');
    
    // Verify error message
    await expect(page.locator('.error-message')).toContainText('Invalid credentials');
  });
});

Contoh Cypress BDD Test Case

Feature: User Login
  Scenario: User logs in with valid credentials
    Given User is on the login page
    When User enters valid email and password
    And User clicks the login button
    Then User should be redirected to dashboard
    And User should see welcome message

Best Practices

  • ✅ Page Object Model (POM) untuk maintainability
  • ✅ Proper wait strategies (explicit vs implicit)
  • ✅ Data-driven testing dengan parameterization
  • ✅ Screenshot & video recording on failure
  • ✅ Parallel test execution untuk faster feedback
  • ✅ Proper cleanup dan teardown
  • ✅ CI/CD integration untuk continuous testing
