API Testing

Automation testing untuk REST API endpoints

Beranda / Proyek Automation / API Testing

Proyek: Mocha-Chai API Testing

Automation testing untuk REST API menggunakan Mocha sebagai test framework dan Chai sebagai assertion library. Proyek ini mencakup testing untuk authentication, CRUD operations, dan status code validation.

🔗 Lihat Repository

Tech Stack

  • Framework: Mocha
  • Assertion Library: Chai
  • HTTP Client: Axios / Node-Fetch
  • Language: JavaScript (Node.js)
  • Reporting: Mochawesome

Scope Testing

Authentication

Testing login flow, token generation, dan authorization headers. Memastikan credential validation berjalan dengan benar.

CRUD Operations

Testing Create, Read, Update, Delete operations pada berbagai endpoint. Validasi response body dan struktur data.

Status Code Validation

Memverifikasi HTTP status codes yang tepat (200, 201, 400, 401, 404, 500, dll) untuk setiap request.

Response Validation

Validasi struktur JSON response, tipe data, dan values. Testing edge cases dan error handling.

Contoh Test Case

Login API Test

describe('Authentication API', () => {
  it('should login successfully with valid credentials', async () => {
    const response = await axios.post('/api/auth/login', {
      email: 'test@example.com',
      password: 'password123'
    });

    expect(response.status).to.equal(200);
    expect(response.data).to.have.property('token');
    expect(response.data.user).to.have.property('email');
  });

  it('should fail login with invalid credentials', async () => {
    try {
      await axios.post('/api/auth/login', {
        email: 'test@example.com',
        password: 'wrongpassword'
      });
    } catch (error) {
      expect(error.response.status).to.equal(401);
      expect(error.response.data).to.have.property('message');
    }
  });
});

Setup & Running Tests

Installation

npm install mocha chai axios mochawesome

Running Tests

npm test
# atau dengan reporter HTML
npm test -- --reporter mochawesome

Best Practices yang Diterapkan

  • ✅ Descriptive test names yang jelas dan mudah dipahami
  • ✅ Organized test structure dengan describe blocks
  • ✅ Proper assertion dan error handling
  • ✅ Test data management dan cleanup
  • ✅ Request/response logging untuk debugging
  • ✅ Timeout configuration untuk API calls yang slow
