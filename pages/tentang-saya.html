Filosofi Testing Saya

Saya percaya bahwa testing bukanlah sekadar mencari bug, tetapi memastikan bahwa setiap fitur bekerja sesuai ekspektasi pengguna. Saya fokus pada:

  • Quality Over Quantity: Test yang meaningful lebih penting daripada banyak test yang tidak berguna
  • Maintainability: Code automation harus clean, readable, dan mudah di-maintain
  • Scalability: Test suite harus dapat berkembang seiring pertumbuhan aplikasi
  • Collaboration: Testing adalah tanggung jawab tim, bukan hanya QA
