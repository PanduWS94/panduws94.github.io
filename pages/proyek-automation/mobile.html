Proyek: Appium Mobile Automation

Automation testing untuk aplikasi mobile (Android) menggunakan Appium dan WebDriverIO. Proyek ini mencakup component testing dan regression testing dengan emulator Android.

🔗 Lihat Repository

Tech Stack

  • Automation Tool: Appium
  • Framework: WebDriverIO / Mocha
  • Platform: Android
  • Device: Android Emulator
  • Language: JavaScript (Node.js)
  • Reporting: HTML Report, Screenshots

Setup & Prerequisites

Requirements

  • Java JDK installed and configured
  • Android SDK & Android Emulator
  • Appium Server
  • Node.js dengan npm

Installation

npm install appium webdriverio @wdio/mocha-framework
npm install --save-dev @wdio/cli

# Start Appium Server
appium

Scope Testing

Touch & Gesture

Testing tap, long press, swipe, scroll, dan gesture lainnya. Memastikan user interactions berfungsi dengan baik.

Element Interaction

Testing button clicks, text input, dropdown selection, checkbox, radio button. Testing berbagai elemen UI di aplikasi mobile.

Navigation

Testing navigation between screens, back button behavior, deep linking, dan push notifications.

Performance

Testing app response time, memory usage, battery consumption. Memastikan aplikasi performant pada berbagai devices.

Contoh Test Case - Login

describe('Mobile App Login', () => {
  beforeEach(async () => {
    // Launch app
    await driver.launch();
  });

  it('should login successfully with valid credentials', async () => {
    // Find email input
    const emailInput = await driver.$('//android.widget.EditText[@text="Email"]');
    await emailInput.click();
    await emailInput.setValue('test@example.com');

    // Find password input
    const passwordInput = await driver.$('//android.widget.EditText[@text="Password"]');
    await passwordInput.click();
    await passwordInput.setValue('password123');

    // Click login button
    const loginBtn = await driver.$('//android.widget.Button[@text="Login"]');
    await loginBtn.click();

    // Wait and verify success
    await driver.pause(2000);
    const welcome = await driver.$('//android.widget.TextView[@text="Welcome"]');
    expect(await welcome.isDisplayed()).toBe(true);
  });

  it('should show error with invalid credentials', async () => {
    const emailInput = await driver.$('//android.widget.EditText[@text="Email"]');
    await emailInput.setValue('test@example.com');

    const passwordInput = await driver.$('//android.widget.EditText[@text="Password"]');
    await passwordInput.setValue('wrongpassword');

    const loginBtn = await driver.$('//android.widget.Button[@text="Login"]');
    await loginBtn.click();

    // Verify error message
    const errorMsg = await driver.$('//android.widget.TextView[@text="Invalid credentials"]');
    expect(await errorMsg.isDisplayed()).toBe(true);
  });
});

Contoh Test Case - Swipe & Scroll

describe('Mobile Gestures', () => {
  it('should swipe to next item in carousel', async () => {
    const carousel = await driver.$('//android.widget.FrameLayout[@resource-id="com.example:id/carousel"]');
    
    // Swipe left
    await driver.touchAction([
      { action: 'press', element: carousel },
      { action: 'moveTo', x: -200, y: 0 },
      { action: 'release' }
    ]);

    // Verify next item is displayed
    await driver.pause(500);
    const nextItem = await driver.$('//android.widget.TextView[@text="Item 2"]');
    expect(await nextItem.isDisplayed()).toBe(true);
  });

  it('should scroll down to load more items', async () => {
    const listView = await driver.$('//android.widget.ListView');
    
    // Scroll down
    await driver.scroll(listView, 'down', 3);
    
    // Verify more items loaded
    const lastItem = await driver.$('//android.widget.TextView[@text="Item 20"]');
    expect(await lastItem.isDisplayed()).toBe(true);
  });
});

Emulator Configuration

Creating Android Virtual Device

android avd  # Android Virtual Device Manager
# atau via command line
sdkmanager "system-images;android-13;google_apis;x86_64"
avdmanager create avd -n "test-avd" -k "system-images;android-13;google_apis;x86_64"

Starting Emulator

emulator -avd test-avd

Locating Mobile Elements

Common Locator Strategies

  • XPath: //android.widget.Button[@text="Login"]
  • Resource ID: //android.widget.Button[@resource-id="com.example:id/login_btn"]
  • Class Name: //android.widget.EditText
  • Content Description: //android.widget.Button[@content-desc="Login Button"]

Tools untuk Inspecting Elements

  • Appium Inspector
  • Android Studio Emulator Device Manager
  • Appium-Python-Client dengan UI Inspector
