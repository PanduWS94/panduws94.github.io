Metodologi Testing

Regression Testing

Memastikan fitur yang sudah ada tidak rusak setelah ada perubahan atau update.

Component Testing

Testing unit-level untuk komponen individual sebelum di-integration.

End-to-End (E2E) Testing

Testing user flow lengkap dari start hingga end untuk memastikan user journey smooth.

Behavior-Driven Development (BDD)

Menggunakan Gherkin syntax untuk mendefinisikan test scenario yang lebih readable.
